

### **1. Редактирование кода**

*   **`Ctrl + C` / `Cmd + C`**: Копировать выделенный текст.
*   **`Ctrl + X` / `Cmd + X`**: Вырезать выделенный текст.
*   **`Ctrl + V` / `Cmd + V`**: Вставить скопированный/вырезанный текст.
*   **`Ctrl + D` / `Cmd + D`**: Дублировать текущую строку или выделенный блок.
*   **`Ctrl + Y` / `Cmd + Delete`**: Удалить текущую строку (если ничего не выделено).
*   **`Ctrl + /` / `Cmd + /`**: Закомментировать/раскомментировать текущую строку или выделенный блок (построчное комментирование).
*   **`Ctrl + Shift + /` / `Cmd + Shift + /`**: Закомментировать/раскомментировать текущую строку или выделенный блок (блочное комментирование).
*   **`Ctrl + Enter` / `Cmd + Enter`**: Вставить новую строку ниже текущей (даже если курсор в конце строки).
*   **`Shift + Enter`**: Вставить новую строку выше текущей (даже если курсор в начале строки).
*   **`Ctrl + W` / `Cmd + W`**: Расширить выделение (по словам, предложениям, блокам кода).
*   **`Ctrl + Shift + W` / `Cmd + Shift + W`**: Сузить выделение.
*   **`Ctrl + Shift + J` / `Cmd + Shift + J`**: Объединить строки.
*   **`Alt + Shift + Up/Down`**: Переместить/скопировать текущую строку вверх или вниз.
*   **`Ctrl + Alt + L` / `Cmd + Alt + L`**: Отформатировать код (привести к единому стилю).
*   **`Tab`**: Вставить отступ.
*   **`Shift + Tab`**: Убрать отступ.


### **2. Навигация**

*   **`Ctrl + B` / `Cmd + B` (или `Ctrl + Click` / `Cmd + Click`)**: Перейти к объявлению символа (переменной, метода, класса).
*   **`Ctrl + Alt + B` / `Cmd + Alt + B`**: Перейти к реализации (для интерфейсов и абстрактных методов).
*   **`Ctrl + Shift + N` / `Cmd + Shift + N`**: Поиск файла по имени.
*   **`Ctrl + N` / `Cmd + N`**: Поиск класса по имени.
*   **`Ctrl + Shift + Alt + N` / `Cmd + Shift + Alt + N`**: Поиск символа (метода, переменной, поля) по имени.
*   **`Ctrl + Shift + F` / `Cmd + Shift + F`**: Поиск по всему проекту (текстовый поиск).
*   **`Ctrl + F` / `Cmd + F`**: Поиск в текущем файле.
*   **`Ctrl + R` / `Cmd + R`**: Замена в текущем файле.
*   **`Ctrl + Shift + R` / `Cmd + Shift + R`**: Замена по всему проекту.
*   **`Ctrl + G` / `Cmd + G`**: Перейти к номеру строки.
*   **`Alt + Left/Right`**: Перемещаться по истории навигации (вперед/назад по тому, где вы были).
*   **`Ctrl + Alt + Left/Right` / `Cmd + Option + Left/Right`**: Перейти к предыдущему/следующему месту редактирования.
*   **`Ctrl + Shift + Backspace` / `Cmd + Shift + Backspace`**: Перейти к последнему месту редактирования.
*   **`F12`**: Вернуться из окна инструмента к редактору.
*   **`Alt + F1`**: Выбрать текущий файл в окнах "Project" или "Structure".

### **3. Поиск и Поиск использования**

*   **`Ctrl + Shift + F` / `Cmd + Shift + F`**: Поиск по всему проекту.
*   **`Ctrl + F` / `Cmd + F`**: Поиск в текущем файле.
*   **`Alt + F7`**: Найти все использования символа.
*   **`Ctrl + Shift + F7` / `Cmd + Shift + F7`**: Подсветить все использования символа в текущем файле.

### **4. Запуск и Отладка**

*   **`Shift + F10` / `Ctrl + R` (macOS)**: Запустить последнее запущенное приложение/тест.
*   **`Shift + F9` / `Ctrl + D` (macOS)**: Отладить последнее запущенное приложение/тест.
*   **`Ctrl + Shift + F10` / `Ctrl + Shift + R` (macOS)**: Запустить текущий файл (если это исполняемый класс или тест).
*   **`Ctrl + Shift + F9` / `Ctrl + Shift + D` (macOS)**: Отладить текущий файл.
*   **`Ctrl + F2` / `Cmd + F2`**: Остановить текущий запущенный процесс.
*   **`Ctrl + Alt + S` / `Cmd + ,`**: Открыть настройки (Settings/Preferences).
*   **`Ctrl + Shift + A` / `Cmd + Shift + A`**: Найти действие по имени (очень полезно, если вы забыли сочетание клавиш).

### **5. Работа с Git**

*   **`Alt + 9`**: Открыть окно Git.
*   **`Alt + Backquote` (` ` )**: Вызвать меню Git (Switch, Update Project, Commit, Push и т.д.).
*   **`Ctrl + K` / `Cmd + K`**: Показать окно Commit.
*   **`Ctrl + Shift + K` / `Cmd + Shift + K`**: Показать окно Push.

### **6. Структура проекта и кода**

*   **`Alt + 1`**: Открыть/скрыть окно Project.
*   **`Alt + 7`**: Открыть/скрыть окно Structure (для текущего файла).
*   **`Ctrl + H` / `Cmd + H`**: Показать иерархию вызовов метода.
*   **`Ctrl + Alt + H` / `Cmd + Alt + H`**: Показать иерархию вызовов.

### **7. Другие полезные команды**

*   **`Ctrl + Shift + E` / `Cmd + Shift + E`**: Открыть список недавно открытых файлов.
*   **`Ctrl + E` / `Cmd + E`**: Открыть список недавно открытых файлов и мест редактирования.
*   **`Double Shift`**: Поиск везде (Search Everywhere) – самый универсальный способ найти что угодно: файлы, классы, символы, действия, настройки.
*   **`Alt + Enter`**: Показать контекстные действия (Quick Fixes, Intentions) – предлагает возможные исправления или улучшения кода.
